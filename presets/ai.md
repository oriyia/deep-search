Когда читать: бриф с `preset: ai` — модели, инструменты для агентов, поставщики моделей, программы для ИИ; на этапе 1 (подсказки для брифа) и ветке на этапе 3.

# Пресет ai

Предметная карта поиска в отрасли ИИ. Общий метод — проходы, шкала, независимость, журнал — в
`references/sources.md`; пресет его не меняет, а дополняет знанием об области. Сводка новинок
без вопроса — не поиск, а сценарий «что нового» (`references/watch.md`).

На этапе 1: `question_type` — «Типы вопроса»; `sources_plan` — «Первоисточники» и «Источники
охвата»; `data_items` и `comparison_criteria` — «Данные для сравнения»; `keywords` — термины из
«Шаблонов запросов». На этапе 3 ветка берёт разделы по своей цели и сверяется с «Ловушками».

## Типы вопроса

| Задача | Как вести |
|---|---|
| Сравнить модели под задачу | `comparison`: критерии — из «Данных для сравнения»; оценки — независимые (B) раньше вендорских (E); у каждой цифры — дата и снимок модели |
| Чем заменить модель, стоит ли переходить | `replacement`: от фактически используемого (контекст, инструменты, цена, регион, лицензия весов) — `inclusion_criteria`; срок жизни текущей модели — страница отключений поставщика |
| Выбрать инструмент для агента (MCP-сервер, фреймворк, CLI-агент) или программу для ИИ | `options`; классы решений — как в пресете `technology` («Типы вопроса»), сведения о репозитории — `deep_search.py facts` |
| Правда ли, что поставщик изменил X (цену, лимит, условия, модель) | `validation`: первоисточник — страница цен, журнал изменений, условия; пересказ в новостях — только повод |
| Что нового в отрасли | не поиск — сценарий «что нового», `references/watch.md` |

Форма дерева по типу — `references/branching.md`, раздел «Форма дерева».

## Первоисточники

Буква — по `references/sources.md`, раздел «Шкала»; в этой области типы источников ложатся так:

- **A** — карточка модели и системная карточка; документация API; страница цен; журнал изменений
  и заметки к выпуску; список моделей в API поставщика (`/v1/models` и аналоги); страница
  отключений; условия использования; статья о модели — для фактов о себе (архитектура, данные,
  заявленные результаты как заявление). Вендор — A о себе, E об оценке себя.
- **B** — воспроизводимые независимые оценки с открытой методикой и данными: Epoch AI, таблицы
  бенчмарков с кодом прогона, рецензируемые работы.
- **C** — LMArena (голоса людей; методика оспаривается — стиль ответа влияет на голос); отчёты об
  использовании и опыт команд с датой и снимком модели.
- **D** — OpenRouter как каталог, рассылки, Telegram-каналы, агрегаторы новостей, обзоры.
- **E** — бенчмарки вендора о себе, маркетинг, сравнения «мы против них», утечки и слухи, выводы ИИ.

Новость только из Telegram или агрегатора без первоисточника — не выше D и с пометкой.

## Источники охвата

Дают охват, а не оценку: найденное здесь проверяется по первоисточникам.

- **OpenRouter** — каталог моделей всех поставщиков без ключа:
  `curl -s https://openrouter.ai/api/v1/models` — цены за токен, контекст, модальности,
  `knowledge_cutoff`, `hugging_face_id`; варианты `:free` и `:batch` — одна модель (`canonical_slug`).
- **Hugging Face** — карточки моделей и организации
  (`https://huggingface.co/api/models?author=<org>&sort=createdAt&direction=-1&limit=5`),
  тренд (`sort=trendingScore`), статьи недели (`/api/daily_papers?week=ГГГГ-Wнн`).
- **LMArena** — данные рейтинга — датасет Hugging Face `lmarena-ai/leaderboard-dataset` через
  `https://datasets-server.huggingface.co/rows?dataset=lmarena-ai/leaderboard-dataset&config=text&split=latest&offset=0&length=100`;
  строки по категориям — брать `category=overall` или нужную; поле `leaderboard_publish_date`.
- **Epoch AI** — каталоги моделей CSV: `https://epoch.ai/data/notable_ai_models.csv`,
  `https://epoch.ai/data/all_ai_models.csv` (дата публикации, организация, параметры, compute);
  отстают на 1–2 недели.
- **Рассылки** — Import AI, Interconnects, Latent Space, блог Simon Willison: что обсуждают и куда
  смотреть; факт — по их ссылке.
- **Хранилище:** `watch/new/*.jsonl` и прежние дайджесты `watch/digests/` библиотеки — что уже
  проходило через мониторинг и когда (`references/watch.md`).
- **Сведения о репозитории** инструмента — `deep_search.py facts`; остальное по ПО —
  `references/apis.md`.

## Ловушки

- **Бенчмарки вендора выборочны:** показаны выигрышные тесты, настройки прогона и число попыток
  не раскрыты — это E; сравнивать на одном независимом наборе с одной методикой.
- **Загрязнение тестов:** задачи публичного бенчмарка могли попасть в обучающие данные — высокий
  балл на старом наборе слабее балла на свежем или закрытом.
- **Дата OpenRouter — не дата выхода:** `created` — появление модели в каталоге; дата выхода — в
  анонсе или карточке поставщика.
- **Preview и общая доступность:** preview, beta, experimental меняются и снимаются без срока;
  цены и лимиты preview не переносить на общую версию.
- **Снимки с датой в имени:** `<M>-2026-08-15` и алиас `<M>-latest` — разные объекты; оценка
  относится к снимку, алиас со временем указывает на другой.
- **Цена зависит от режима:** длина контекста (порог, после которого цена выше), batch, кэш
  промптов, «думающий» режим, выходные токены; сравнивать цену одной задачи, а не строку прайса.
- **Доступность по регионам:** модель есть в API, но не в стране, облаке или у посредника;
  доступ через облако поставщика (Bedrock, Vertex, Azure) отстаёт и стоит иначе.
- **Пересказ вместо факта:** Telegram и рассылки повторяют друг друга — независимость по
  `references/sources.md`, раздел «Независимость», а не по числу каналов.
- **Будущие даты в журналах:** на страницах изменений даты бывают сроками отключения, а не датами
  записей.

## Данные для сравнения

По каждой модели — с источником и датой; отсюда `data_items` и `comparison_criteria`:

| Данные | Где брать |
|---|---|
| Контекст и предел вывода | документация API, OpenRouter |
| Цены: вход, выход, кэш, batch, пороги контекста | страница цен поставщика; OpenRouter — для сверки |
| Модальности: текст, изображение, звук, видео, инструменты | карточка модели, документация |
| Лицензия весов (открытые веса — какие ограничения) | карточка на Hugging Face, файл лицензии |
| Где доступна: API, веса, облака, регионы | документация, страница доступности, каталоги облаков |
| Независимые оценки | Epoch AI, бенчмарки с открытой методикой, LMArena — с оговоркой C |
| Дата выхода | анонс или карточка поставщика, Epoch AI |
| Дата среза знаний | карточка модели, `knowledge_cutoff` OpenRouter |

## Свежесть

Классы для области; сроки перепроверки — `references/sources.md`, раздел «Свежесть»:

- **V3** — цены, лимиты, доступность, список моделей в API, сроки отключения;
- **V2** — возможности модели и инструмента, результаты в рейтингах;
- **V1** — архитектура, статьи, история выпусков.
