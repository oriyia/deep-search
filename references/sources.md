Когда читать: этап 3 — ветке и ведущему: проходы, запросы, шкала A–F × 1–6, свежесть, красные флаги, журнал и улики.

# Источники

Содержание: Проходы · Обязательные приёмы · Запросы · Инструменты · Шкала · Независимость · Свежесть ·
Красные флаги · Журнал и улики. Ветке хватает задания, этого файла и пресета; поля брифа — в задании.

## Проходы

1. **Пробный.** 2–3 запроса; из выдачи — термины: как называют профессионалы, синонимы, известные
   представители. Новые термины — в `note` журнала.
2. **Охват.** Каталоги, ландшафты, подборки, обзоры — это D, фильтр внимания, а не подтверждение.
   Знания модели — E: только гипотезы и ключевые слова, не находки.
3. **Проверка.** Каждую находку — по первоисточнику, от A к E: код, документация версии, реестр,
   затем независимые измерения, затем опыт эксплуатации. D и E — только указатели, где искать.
4. **Расширение по связям (TARCiS).** Старт — находки и `known_items`. Направления: альтернативы и
   сравнения («X vs», «X alternative»); переходы туда и обратно («migrated from X to», «moved away
   from X»); форки и преемники; соседи по каталогу; для науки — цитирования вперёд и назад. Круги —
   пока появляется новое; круг без новых объектов закрывает направление.

На уровне S — пробный проход и проверка. Когда остановить ветку — задание и `references/branching.md`,
раздел «Остановка».

## Обязательные приёмы

- **Запрос-опровержение** к каждому ключевому выводу: неудачный опыт, постмортемы, уход с решения,
  отзывы, ретракции («X problems», «X postmortem», «migrated away from X», «отказались от X»).
  Нашлось — улика против; не нашлось — строка журнала «искали, не нашли».
- **`current_assets`** — первой проверкой: не закрывает ли потребность то, что уже есть.
- **`prior_work` и `exclusions`** — отклонённое повторно не исследуется. Новые данные о нём
  (версия, лицензия, условия) — отдельной уликой с пометкой «к отклонённому».
- **Боковое чтение:** незнакомый источник до буквы выше D — 1–2 запроса о нём самом: кто владелец,
  что о нём пишут другие.

## Запросы

- 2–5 слов; на русском и английском, плюс языки из `limits`. Понятия — из `keywords`: синонимы
  блока через OR, блоки через AND; фразы — в кавычках.
- Шаблоны по назначениям — пресет, раздел «Шаблоны запросов».
- Сначала широко, потом узко: фильтры (сайт, период `since`, тип файла) — после пробного прохода.
- Перед запросом — сверка с журналом: повтор — петля; сменить тактику (другой блок, язык, источник,
  направление связей).
- Пустая выдача — переформулировать не больше двух раз (синоним, шире, другой язык); затем статус
  `not_found` и перечень попыток.
- **`disclosure_constraints`** — каждый запрос и каждый URL для внешнего сервиса сверить с ним;
  запрещённое название или имя заменить родовым понятием.
- **Тест `known_items`** — после охвата отметить, какие из них стратегия нашла сама, а не поиском по
  имени. Меньше 80 % — стратегия слепая: добавить синонимы, языки, источники. Находит только их —
  тоже тревожно: выдача узкая, расширить. Итог — в `note` и в ответ ветки.
- **PRESS** (начиная с M) — самопроверка набора запросов после пробного прохода:
  1. перевод вопроса — все понятия вопроса есть в запросах, лишних нет;
  2. синонимы — термины профессионалов, аббревиатуры, варианты написания;
  3. операторы — OR внутри блока, AND между блоками, кавычки, без перегруза;
  4. ограничения — даты, язык, домены оправданы и не отсекают нужное;
  5. опечатки и написание имён;
  6. перевод на другие языки. Итог — в `note` журнала: «PRESS: ок» или что исправлено.

## Инструменты

Краткая лестница; команды, ловушки и API — `references/environment.md`.

1. **Специализированные источники прежде общего веба:** документация библиотек — context7; ПО —
   GitHub API и raw, deps.dev, endoflife.date, OSV, ecosyste.ms, Scorecard; наука — OpenAlex, arXiv,
   Crossref. В журнале — `method: api`.
2. **WebSearch** — обнаружение: заголовки и URL. Сводка поверх выдачи — не источник.
3. **Текст для фактов и цитат:** curl + pandoc; PDF — `pdftotext`; JS-страница — headless Chromium;
   `r.jina.ai` — только если позволяют `disclosure_constraints`.
4. **WebFetch** — только сортировка: стоит ли открывать. Это пересказ малой моделью: число и цитата —
   по тексту из п. 3; «страница не упоминает X» — не отрицание.
5. **Мёртвая ссылка** — Wayback: устарела или выдумана.

Что доступно — `env` в `manifest.json` прогона. Ступень недоступна — следующая, с пометкой в `note`.

## Шкала

Оценивается пара «источник × утверждение». Код — `<буква><цифра>[!]`: `A1`, `B2`, `C3!`, `E4`.
Буква — по лучшему поддерживающему источнику.

**Буква — надёжность источника для этого утверждения.** Вопросы сверху вниз, букву даёт первый
подошедший:

| | Вопрос | Примеры |
|---|---|---|
| F | Неясно, кто стоит за источником, и боковое чтение ничего не дало? | страница без владельца |
| E | Заинтересован в утверждении или неподотчётен? | маркетинг, пресс-релиз, партнёрский обзор, ферма контента, соцсети, выводы ИИ |
| A | Происхождение или официальная запись факта нужной версии и даты? | код, документация версии, LICENSE, changelog; официальное опубликование; реестр; статья — для своих результатов |
| B | Независим, наблюдал сам, метод воспроизводим? | бенчмарк с данными, рецензируемое исследование, официальная статистика, оригинальный репортаж |
| C | Свидетельство из первых рук без метода, автор установим? | отчёт об эксплуатации, постмортем, доклад, препринт без данных |
| D | Пересказ, сводка, мнение без доступа к факту? | радары, каталоги, энциклопедии, новости-пересказы, форумы |

- Буква — по происхождению, а не по сайту: материал вендора на чужом сайте остаётся E; чужой текст
  на авторитетном домене его букву не наследует.
- Вендор — A для фактов о себе (лицензия, выпуск), E для оценок себя и сравнений с конкурентами.
- Каждый красный флаг и каждая косвенность (другая версия, другая среда) понижают букву на ступень.

**Цифра — подтверждённость утверждения:**

| | | Условие |
|---|---|---|
| 1 | подтверждено | открытый A нужной версии (для «документ говорит X») или ≥2 независимых A/B без противоречащих A/B |
| 2 | вероятно | один A/B или ≥2 независимых C; противоречий нет |
| 3 | возможно | один C; любое число D; неснятое противоречие сопоставимых — метка `!` |
| 4 | сомнительно | только E или всё восходит к одному E |
| 5 | опровергнуто | противоречит A или ≥2 независимым B |
| 6 | нельзя судить | страница не открыта (сниппет, пейвол), источник не найден, истёк срок свежести |

- Потолки: только E — не выше 4; только D — не выше 3; один C — 3; один B — 2.
- «1» по одному A — только для содержания документа, кода, реестра. «Так работает на практике»,
  исключительное утверждение и `stakes: high` — «1» только по двум независимым A/B.
- Отрицание («не поддерживает») — «1», только если A прямо пишет «не поддерживается»; иначе не выше 2
  в форме «не найдено в <источники, дата>».
- Слабое хранится с атрибуцией: «по заявлению вендора, …» — атрибуция A1, содержание E4.
- Какая цифра нужна ключевым утверждениям — `min_confirmation` брифа; умолчания по `stakes` —
  `references/brief.md`, раздел «Поля».

Ветка ставит букву каждой улике и предварительный код своим утверждениям. Окончательную цифру ставит
ведущий при сведении по уникальным `orig` — `references/verify-merge.md`, раздел «Сведение».

## Независимость

Два источника независимы, если ни один не взят из другого и у них нет общего происхождения. У каждой
улики — поле `orig`: самое раннее найденное происхождение факта (кто первым опубликовал или измерил).

Один источник, а не несколько: совпадающие формулировки и цифры; ссылки на один материал; синдикация;
пересказ пресс-релиза; общий владелец; энциклопедия как источник для СМИ; один вендорский бенчмарк в
нескольких обзорах. Две улики ветки с одним `orig` — одно подтверждение. Чужих веток ветка не видит:
её дело — честный `orig`, пересчёт — у ведущего.

## Свежесть

Две даты: публикации или изменения источника и проверки утверждения; у версионных фактов — «на версии
X». Сведения нужны на `as_of_date` брифа, пусто — на сегодня. Класс изменчивости ставит ветка
утверждению:

| Класс | Что | Срок перепроверки |
|---|---|---|
| V0 | неизменное: история, спецификация по постоянной ссылке | только при исправлениях и ретракциях |
| V1 | медленное: нормы, архитектура, консенсус | 12 месяцев |
| V2 | среднее: лицензия, сопровождающие, сроки поддержки, тарифы | 90 дней |
| V3 | быстрое: последний выпуск, цены, события, звёзды | 7–30 дней и перед любым решением |

Просроченное получает «6» и служит гипотезой до перепроверки. Новее — не значит надёжнее: свежую дату
легко подставить; дату брать из changelog, коммита, реестра.

## Красные флаги

| Флаг | Действие |
|---|---|
| нет владельца или автора | F |
| конфликт интересов: оценка себя, пресс-релиз, спонсор | E для оценок |
| ферма контента: тексты без автора, переписывание, нераскрытый ИИ-текст | E |
| обзор с партнёрскими ссылками | D или E; искать испытания |
| benchmarketing: нет конфигурации, версий, данных, кода; одна нагрузка; нет разброса | не выше C |
| накрученная популярность: звёзды, отзывы | не подтверждение |
| хищнический журнал, бумажная фабрика | E |
| отозванная статья (проверка — Crossref, `references/environment.md`) | не использовать |
| препринт | метка; B при открытых данных, иначе C |
| наука в пересказе пресс-релиза | идти к статье |
| сведения только от вендора; уход сопровождающих; лицензия строже; один основной участник | признак против — в ответ ветки |

## Журнал и улики

**Журнал** — `branches/<task_id>.jsonl`, объект на строку, строка на действие: запрос, открытая
страница, шаг по ссылкам, вызов API. Пишется по ходу, а не в конце.

| Ключ | Что |
|---|---|
| `ts` | дата и время ISO 8601 |
| `branch` | `task_id` |
| `method` | `query` · `browse` · `citation` · `api` |
| `source` | платформа или URL |
| `query` | строка в точности как выполнена |
| `filters` | даты, язык, домены; нет — `""` |
| `shown`, `screened` | сколько выдано, сколько просмотрено |
| `kept` | id новых объектов или улик, списком |
| `dupes` | число дублей |
| `note` | зачем действие и что изменилось в понимании |
| `capture` | только у ключевых страниц: архивный URL и sha256 текста |

```json
{"ts":"2026-10-05T14:02:11+03:00","branch":"B2","method":"query","source":"WebSearch","query":"log search self-hosted OR open source","filters":"","shown":10,"screened":6,"kept":["ev3"],"dupes":2,"note":"пробный проход: термин «log management»"}
```

**Улики** — `branches/<task_id>.md`, строка на улику:

`ev<N> | <дата> | <буква> | <URL> §<место> | orig: <происхождение> | → <ключ утверждения> | «<цитата ≤25 слов>»`

- `<дата>` — дата проверки, ISO; дату публикации источника писать в `orig` после происхождения,
  нет её — «б/д».
- `§<место>` — раздел, заголовок, страница PDF или строка, чтобы цитату нашёл другой.
- Цитата — дословно из открытого текста, не из сниппета и не из пересказа WebFetch.
- `<ключ утверждения>` — ключ из ответа ветки (`references/branching.md`, раздел «Контракт ветки»);
  ссылка на улику из другой ветки — `<task_id>:ev<N>`.

`ev3 | 2026-10-05 | A | https://www.postgresql.org/docs/17/release-17.html §E.12.3.1.7 | orig: release notes PostgreSQL 17, 2024-09-26 | → incremental-backup | «Incremental backups can be created using pg_basebackup's new --incremental option.»`
