# Проверка источников-кандидатов (технологии и наука)

**Проверено 2026-10-09** реальными запросами curl с одного IP. «HTTP» — код ответа на рабочую команду в этот день.
Уже есть в скилле: context7, GitHub API, deps.dev, endoflife.date, OSV, ecosyste.ms, OpenSSF Scorecard, OpenAlex, arXiv, Crossref, Wayback.
Сырые ответы не сохранялись.

Цитаты лимитов — с официальной страницы; где официальной страницы нет или она не отдаётся, это сказано явно, и лимит взят из заголовков ответа (помечено «заголовок»).

## Сводка

- **Годны без ключа:** Codeberg/Forgejo, Repology (UA + ≤1 запрос/с), Wikidata SPARQL + wbsearchentities (обязателен описательный UA), Europe PMC (биомедицина), API опубликования pravo.gov.ru.
- **С оговорками:** GitLab (60/час по документации), Gitee (60 без токена), Software Heritage (не браузерный UA, иначе Anubis), Stack Exchange (300/день, gzip), Unpaywall (нужен реальный email), Sourcegraph stream (анонимно работает, но не задокументировано), grep.app (только через MCP `mcp.grep.app`), Wayback CDX (нестабилен: 503/429), Libraries.io (документация требует ключ), КиберЛенинка (поиск — внутренний API под запретом robots; легально — OAI-PMH), ИПС pravo.gov.ru (cp1251, медленно).
- **Требуют бесплатный ключ/аккаунт:** Semantic Scholar (без ключа — сплошные 429), SPN2 (S3-ключи archive.org), GitFlic (токен), Libraries.io (по документации), Stack Exchange (ключ поднимает до 10 000/день).
- **Не годны:** GitHub code search без токена (401), GitFlic без токена (403), archive.today (нет соединения, нет API), REST grep.app (Vercel checkpoint).
