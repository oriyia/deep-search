# 04. Боковое чтение Telegram-каналов об ИИ

**Проверено 2026-10-09.** Вопрос: годится ли канал как источник *обнаружения* новостей. Для
подтверждения фактов каналы не используются: факт проверяется по первоисточнику, на который канал
ссылается.

Имена авторов, их личные профили и контакты в этой версии отчёта опущены: в таблице — только чем
подтверждена связь канала с публичным специалистом.

## Метод и ограничения

Метод — боковое чтение (SIFT). По каждому каналу:
1. лента `t.me/s/<канал>`, последние 8–20 постов: описание, пометки «реклама», «erid», «#промо»,
   курсы, репосты, внешние ссылки;
2. внешние источники, которые называют автора вместе с каналом: СМИ, профили на GitHub и Хабре,
   личные сайты, arXiv, подкасты, анонсы мероприятий;
3. упоминания вне каталогов;
4. карточка канала на рекламной бирже: есть цена — канал продаёт рекламу.

Ограничения:
- Открытая страница TGStat без входа не показывает индекс цитирования и упоминания: накрутку
  аудитории проверить не удалось ни по одному каналу.
- Поиск по Хабру отдаёт капчу; упоминания искались веб-поиском. «Не найдено» значит «не найдено за
  2–4 запроса», а не «нет».
- Часть фактов — из выдачи поиска, страница не открылась; в таблице помечено **[сниппет]**.
- Связь «канал ↔ человек» засчитана, только если внешний источник называет канал вместе с автором;
  совпадение ника — «косвенная».

Слабые сигналы — подборки: vc.ru «80+ ТГ каналов про ИИ» (2026-08-04) и РБК Тренды «10 телеграм-каналов
про технологии».

`watch`.
